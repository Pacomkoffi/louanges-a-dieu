# Recueil de Cantiques LOUANGES À DIEU

934 cantiques, recherche par numéro, titre ou paroles, favoris, mode nuit. Fonctionne sans internet.

**Auteur :** Centre Missionnaire du Message Évangélique de la Fin des Temps — Île Boulay (Côte d'Ivoire)
**Gratuit pour le peuple de Dieu**

Pour toute suggestion : centremissionnaire.ileboulay@gmail.com

## Installer l'application
- **Android (Chrome)** : ouvrez https://pacomkoffi.github.io/louanges-a-dieu/ puis touchez **Installer**.
- **iPhone (Safari)** : ouvrez le lien, touchez **Partager**, puis **Sur l'écran d'accueil**.
